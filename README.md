# binary-analysis-ida
Этот репозиторий содержит мои заметки и разборы crackme-задач по $$reverse engineering$$
Здесь я собираю:
- анализ поведения бинарников;
- поиск и обход анти дебаг проверок;
- восстановление логики валидации;
- написание простых кейген-решений;
- патчинг бинарников;
- заметки по инструментам и подходам, которые использую в работе.

тулсы

В работе использую следующие инструменты и плагины:
- Detect It Easy
- x64dbg
  - ScyllaHide
  - ApiBreak
  - xAnalyzer
- IDA Pro 8.3
